# Gracenote

> Gracenote, a Nielsen company, is the entertainment metadata and content-identification business
> behind TV guides, music recognition, sports data and in-car entertainment. It publishes ten
> first-party OpenAPI 3.1.1 definitions covering 298 operations, and two production Model Context
> Protocol servers for video and sports.

Generated by API Evangelist on 2026-09-12 from the artifacts in this repository. Gracenote does not
publish an llms.txt of its own; https://devportal.gracenote.com/llms.txt returned 403 and
https://gracenote.com/llms.txt returned 404 on 2026-09-12.

Access is licensed, not self-serve. A developer-portal account can be created freely; an API key
requires a sales conversation. REST products authenticate with an API key (api_key query parameter on
the OnConnect family, GN-APIKEY header on GMD v3 and GN IDS). The MCP servers use OAuth 2.0 with
dynamic client registration and a documented machine-to-machine client-credentials flow.

  gnv_web_search, gnv_get_cast, gnv_get_awards, gnv_get_ratings. OAuth 2.0 required; anonymous

## API definitions

- [On API v3.28](https://devportal.gracenote.com/catalog/on-api): 19 operations. TV schedule and
  program ingestion. Base https://on-api.gracenote.com
- [OnConnect Lookup APIs v1.1](https://devportal.gracenote.com/catalog/onconnect): 40 operations.
  Programs, series, celebrities, lineups, stations, theatres, sports airings. Base
  https://data.tmsapi.com/v1.1
- [GVD API v3.06](https://devportal.gracenote.com/catalog/gvd): 13 operations. Global video data,
  availability and catalog feeds. Base https://gvd-api.gracenote.com
- [GN IDS API v1.9.3](https://devportal.gracenote.com/catalog/gnids): 74 operations. The only write
  surface — create, update, delete and publish programs to Gracenote-licensed datasets. Base
  https://gnids.gracenote.com/api/v1
- [GMD API v2.0](https://devportal.gracenote.com/catalog/gmd-v2): 8 operations. Music metadata —
  artists, recordings, album editions, tracks, descriptors. Base
  https://api.gmd.music.gracenote.com/v2
- [GMD API v3.0 Beta](https://devportal.gracenote.com/catalog/gmd-v3): 13 operations. Interfaces are
  subject to change. Base https://api.gmd.music.gracenote.com/v3
- [Nexus API v1.1.5](https://devportal.gracenote.com/automotive/nexus-auto/nexus-api-dev-guide/api-reference):
  39 operations. In-car entertainment — music, podcasts, radio stations, sports, video, collections.
  Base https://api.nexus.gracenote.com/v1
- [Global Sports Data Lookup API v1](https://devportal.gracenote.com/catalog/global-sports): 73
  operations. Sports, leagues, seasons, matches, teams, persons, standings, venues. Base
  https://api.sports.gracenote.com/gns-api
- [Global Sports Data Update API v6](https://devportal.gracenote.com/catalog/global-sports-data): 13
  operations. Update/ingestion feed.
- [Online Video and Social APIs v2.0](https://devportal.gracenote.com/catalog/onconnect-video-social):
  6 operations. OTT video links and social signals indexed to TMS IDs.

## Conventions an agent should know

- Identifiers are the product. tmsId identifies a published program; rootId groups alternate-language
  versions; gnID is the write surface's key. Resolve to an identifier before asking for anything else.
- Pagination is offset/limit. Gracenote recommends a maximum limit of 1000 across all endpoints.
- Errors are a flat JSON envelope: {"status": 400, "error": "invalid_query_parameter_value",
  "description": "..."}. Not RFC 9457.
- Rate limits are per-contract and unpublished. There are no rate-limit response headers. Exhaustion
  is a 429 with error rate_limit_exceeded (GMD) or quota_limit_exceeded (Nexus); a 403 with
  plan_limit_exceeded is a separate plan-level ceiling.
- In the Nexus API, null means the field does not apply to that object; empty string means the field
  applies but is missing. Nexus responses are pre-sorted — do not re-sort.
- There is no idempotency key anywhere, on any of the 45 write operations. There is no dry-run mode.
- Deletes exist for every GN IDS create, but POST /publish has no documented unpublish and no window.

## Limits and gaps

- No pricing is published. No self-serve tier, no free tier, no trial.
- No status page. Incident and release communication runs through Help Center notifications.
- No security.txt, no vulnerability disclosure policy, no trust center, no published certifications.
- No first-party SDK on any public package registry. GNSDK and the Nexus Auto SDK are licensed
  downloads from a Flexera-hosted entitlement portal.
- Six of the ten specs declare 200 responses only, so an agent cannot learn failure modes from them.

## Not a Gracenote product

- https://gracenote.com/wp-json/mcp/mcp-oauth-server is an MCP endpoint served by the WordPress VIP
  platform running the gracenote.com marketing site. It exposes site content, not metadata products.
